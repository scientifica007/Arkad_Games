# Retro Arcade — صالة الألعاب الكلاسيكية

تطبيق Web عربي مستقل يحتوي على **3 ألعاب أصلية قابلة للعب**:

1. **غزاة الفضاء (Space Shooter):** سفينة، موجات فضائيين، قذائف، ثلاث محاولات ودرجات صعوبة متصاعدة.
2. **تحطيم الطوب (Breakout):** كرة ومضرب، فيزياء ارتداد، مراحل متجددة وثلاث محاولات.
3. **المتاهة (Maze Chase):** متاهات تولّد آليًا وقابلة للاستكشاف بالكامل، جمع نقاط، مطاردون يبحثون عن مسار وقوة مؤقتة.

## التشغيل الفوري

- على **Windows أو Linux أو macOS**: فك ضغط الأرشيف وافتح ملف `index.html` في متصفح حديث مثل Chrome أو Edge أو Firefox. لا تحتاج إلى تثبيت ولا إلى اتصال بالإنترنت.
- على **Android**: انشر مجلد المشروع على استضافة HTTPS ثابتة (مثل GitHub Pages) وافتح الرابط من Chrome أو Brave. بعض مديري ملفات Android لا يسمحون بتشغيل صفحات HTML المحلية بشكل صحيح.
- للاستعمال المحلي عبر HTTP: افتح الطرفية داخل المجلد ونفّذ `python3 -m http.server 8080`، ثم افتح `http://localhost:8080`.

## التحكم

| اللعبة | لوحة المفاتيح | الهاتف واللمس |
|---|---|---|
| غزاة الفضاء | ← → للحركة، Space للإطلاق | سهما الحركة وزر الإطلاق؛ يمكن تحريك المركبة بالسحب على الشاشة |
| تحطيم الطوب | ← → أو حركة المؤشر، Space لإطلاق الكرة | أزرار يمين/يسار أو سحب على ساحة اللعب، وزر الإطلاق |
| المتاهة | الأسهم أو W A S D | الأسهم الأربعة أو السحب داخل ساحة اللعب |

- `Enter` أو `Space` لبدء اللعب من شاشة الاستعداد.
- `Esc` أو `P` للإيقاف المؤقت والمتابعة.
- `R` لإعادة الجولة.
- يمكنك تبديل الألعاب من القائمة في أي وقت.
- الصوت: مؤثرات تركيبية أصلية **اختيارية ومغلقة افتراضيًا**، دون موسيقى.

## النتائج والخصوصية

يُحفظ أعلى رقم قياسي وعدد الجولات المنتهية لكل لعبة باستخدام `localStorage` داخل المتصفح. لا توجد حسابات أو تتبع أو خدمات خارجية. حذف بيانات الموقع أو استعمال متصفح مختلف يؤدي إلى بدء سجل جديد.

## PWA والعمل دون إنترنت

المشروع يحتوي على `manifest.webmanifest` و `sw.js` وأيقونات PWA. عند استضافته على HTTPS يمكن تثبيته كتطبيق، ويخزن عامل الخدمة ملفات الواجهة والألعاب للاستخدام دون اتصال. **فتح `index.html` محليًا يعمل دون إنترنت، لكنه لا يفعّل Service Worker أو التثبيت كـ PWA.**

**ملاحظة:** Google Drive مكان لتسليم ملفات المشروع وليس خدمة استضافة صالحة لتشغيل تطبيق Web ديناميكي. لتقديم رابط لعبة قابل للمشاركة ينبغي نشر الملفات على استضافة مواقع ثابتة.

## التقنيات والملكية

HTML5 + CSS3 + JavaScript + Canvas API، دون حزم أو اعتماديات أو خطوط خارجية. آليات اللعب مستلهمة من أنواع الأركاد الكلاسيكية، وجميع الرسومات والمؤثرات مُنشأة داخل المشروع ولا يُعاد توزيع ملفات أو صور أو أصوات الألعاب التجارية الأصلية.

الإصدار: `1.0.0` — 05/11/2026.

## نشر المشروع على GitHub Pages

1. أنشئ مستودعًا **عامًا Public** جديدًا، باسم مقترح `Retro-Arcade-Web`.
2. ارفع محتويات هذا المجلد إلى جذر الفرع `main` (وليس داخل مجلد فرعي).
3. في Settings → Pages → Build and deployment اختر **GitHub Actions**.
4. انتقل إلى Actions وانتظر اكتمال مهمة **Deploy GitHub Pages** أو أعد تشغيلها يدويًا.
5. افتح عنوان الموقع المنشور في صفحة Pages. يعمل التطبيق تحت مسار المستودع بفضل الروابط النسبية.

توجد مهمتا GitHub Actions: اختبار JavaScript آلي ونشر صفحات ثابتة. تشغيل الاختبارات: `node --test tests/logic.test.js`.
